# Pause – native proof of concept

Se `docs/orch/PLAN-native.md`. Kræver Xcode 15+ på en Mac (macOS 13+).

```bash
cd native
swift run          # eller: open Package.swift i Xcode og tryk Run
```

Trin 1: menulinjeikon (vandråbe) åbner og skjuler et tomt, gennemsigtigt panel.
Ikke bygget eller kørt endnu: sessionen kører Linux uden Swift.
